== Grounded answer artifacts and actions

`uiArtifacts`와 `uiActions`는 LLM 출력이 아니라 검증된 `EvidenceFact`에서 조립한다.
공개 schema의 단독 소유자는 `docs/CHATBOT_API_CONTRACT.md`이며 이 문서는 AI 운영자가
지켜야 할 생성 경계만 설명한다.

허용 artifact는 `factList/v1`, `tradeTable/v1`, `trendTable/v1`,
`comparisonTable/v1`, `recommendationCards/v1`, `recommendationTable/v1`
여섯 종류다. 허용 action은
`focusComplex/v1`과 `showNearbyCategory/v1`이다. 임의 Markdown/HTML, generic renderer payload,
`mapPoints`, chart schema, dynamic plugin은 만들지 않는다.

모든 표시 fact는 observation에 존재하는 `factIds`를 사용한다. 정상적으로 관측할 수
없는 비교 cell은 이유를 표시하되 존재하지 않는 fact id를 만들지 않는다. payload
개수·문자열·직렬화 크기 제한을 넘거나 schema가 잘못된 항목은 공개 response 조립 전에
제외한다. JSON과 SSE는 검증이 끝난 동일한 artifact/action 집합을 반환한다.

지도 action은 marker-safe 단지 좌표 fact만 사용한다. ai-service는 Kakao API를
호출하지 않고, Kakao 장소 응답·전화·URL을 대화나 archive에 저장하지 않는다.

`uiSummary/v1`은 범위 해석, 한 문장 결론, 적용 조건, 조건별 해석, 후속 안내를
분리한다. 사실 문장은 observation의 `factIds`를 사용하고 Web은 strict shape가
유효할 때만 구조화 레이아웃을 표시한다. unknown version 또는 malformed summary는
무시하며 기존 `answer` text fallback은 항상 남긴다.

`recommendationTable/v1`은 고정 조건 catalog의 `TRANSIT`, `ACADEMY`, `SCHOOL`,
`SHOPPING`만 표시한다. `MIN_UNIT_COUNT`는 후보 관측 전에 적용하고 여러 metric은 사용자가
명시한 우선순서로만 정렬한다. `CHILDCARE`는 타입과 source 구현을 보존하지만 active 추천
catalog와 runtime allowlist에서는 제외한다.
