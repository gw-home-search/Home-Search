== edu.academy-registry

17개 교육청 `acaInsTiInfo` page를 완전 수집한다. 전화번호와 교습비는 normalized projection에서 제외한다.
NEIS gateway 호환을 위해 JSON format은 `Type=json` query로 고정하고 HTTP `Accept`는
`*/*`를 사용한다. live `개원` status는 `OPEN`으로 정규화한다. 안정 ID가 있지만
`ACA_NM`만 공란인 row는 `명칭 미제공`, `nameMissing=true`, exact-match key `NULL`로
보존한다. 정확한 `observed_at`은 acquisition과 projection evidence에 유지하되
같은 날 의미가 같은 행의 checksum에서는 제외하며, 이 계약은
`academy-registry-v4`로 구분한다.

=== Grounded summary 경계

`academy_registry_summary`는 property read view에서 시도·시군구 ancestor를 먼저
해석하고, 별도 AI DB에서 교육청명과 시군구명을 exact match한다. 공개 근거는 등록
총수, 운영 수, 관측일로 제한하며 반경·거리·교육 품질 표현은 허용하지 않는다.
NEIS source 상세 페이지의 `이용 허락 범위 제한없음` 표시를 검토해 private raw
저장과 내부 파생 가공을 승인했다. 검토 evidence SHA-256은
`ce16b39dff31b1a41ea9cb8f362310c56258e725c5f470e4347cf81b73d4aac8`이며 공개
재배포는 보수적으로 금지한다. live readiness 승인 전에는 runtime allowlist에
추가하지 않는다.
