== place.sbiz-academy

tracked taxonomy fingerprint와 교육업종 소분류 allowlist가 일치할 때만 게시한다.

=== Tracked taxonomy provenance

공식 업종코드 원문은 공공데이터포털 `15067631`의 2023-02-28 CSV이며, 포털에
대분류 10개·중분류 75개·소분류 247개와 이용허락범위 제한 없음으로 게시되어 있다.
원본 CP949 bytes SHA-256은
`3055e458f887b3c0b94a2059c3a2571a28053de8b17a4e2e566d6b189f6e1948`이고,
저장소에는 UTF-8/LF로 정규화한 247행 artifact와 별도 checksum을 추적한다.

collector는 추적 CSV에서 canonical 대·중·소 artifact를 결정적으로 생성하고 매
acquisition raw bundle에 포함한다. legacy taxonomy endpoint의 현행 분류는 공식 tracked
taxonomy와 달라 계약 근거로 사용하지 않는다. 18개 교육업종 partition의 실제 store
row는 `indsSclsCd`와 `indsSclsNm`이 tracked allowlist와 정확히 일치해야 하며,
불일치나 schema 오류는 publication을 차단한다. source 상가업소 API의
`이용허락범위 제한 없음`, 제공기관,
국세청/카드사 원천 고지와 공공데이터포털 제3자 권리 정책을 함께 검토했다. 검토
evidence SHA-256은
`e66a879b6ce35af441c4b92b58711c7a2d7d538c87659883da6ab298fd98c86d`다. 제3자
provenance를 기록하고 private raw·내부 파생만 승인했으며 공개 재배포는 금지한다.

공식 OpenAPI 명세의 store field는 `bizesId`, `bizesNm`, `indsSclsCd`,
`indsSclsNm`, `rdnmAdr`, `lnoAdr`, `newZipcd`, `adongCd`, `lat`, `lon`을 사용한다.
adapter는 `indsSclsCd`와 `indsSclsNm`이 tracked allowlist와 함께 일치해야만 row를
정규화하며, 신우편번호는 `newZipcd`에서만 읽는다. 전화번호 field는 projection하지
않는다.

=== Grounded location 경계

`academy_lookup`은 기본 800m, 명시 범위 100..2,000m에서 최대 5개 교육업소를
거리순으로 조회한다. 좌표가 유효한 Sbiz 교육업소 위치는 B등급 근거이며, Unicode
NFKC 상호명과 공백 canonical 도로명주소가 모두 exact match하고 양쪽 우편번호가
있으면 그 값도 같은 경우에만 NEIS A등급 등록 근거를 추가한다. punctuation 제거,
유사도, 음절거리, LLM match는 허용하지 않는다.

전국 좌표 coverage 95% 미만이면 답변 생성을 차단한다. property 법정동 코드와 Sbiz
행정코드의 검증된 mapping이 없으므로 지역 90% coverage와 정상 0건은 확정하지
않으며 `verifiedZero=false`를 유지한다. Sbiz 수를 공식 등록 학원 수로 표현할 수
없고, exact match되지 않은 결과는 교육업소 위치로만 표현한다. 실제 taxonomy,
coverage, S3 복구, JSON/SSE grounding과 최대 반경 성능은 readiness에서 통과했으며,
runtime allowlist 변경은 별도 activation commit에서만 수행한다.
