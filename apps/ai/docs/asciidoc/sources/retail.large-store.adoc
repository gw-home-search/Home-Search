== retail.large-store

기존 LOCALDATA CSV는 stale source date와 공란 이용허락 때문에 운영 acquisition에서
제외했다. collector는 공공데이터포털의 행정안전부 `생활_대규모점포 조회서비스`
`GET /info`만 호출한다. 공식 계약은 일간 갱신, 2일 전 기준 현행화,
`numOfRows` 최대 100, `totalCount` pagination을 명시한다. 정확한 release date를
제공하지 않으므로 lifecycle은 수집 시작 UTC를 `OBSERVED_AT`으로 사용한다.

source 상세의 `이용허락범위 제한 없음`을 source별로 검토했으며 private raw 저장과
내부 파생만 승인한다. raw 공개 재배포는 제품 정책상 비활성화한다. license evidence
SHA-256은 `02bce96a68d777801a4e5ac4cfe71c3e8d9d958ef20eb8a8eb362dc21e6fe2d4`다.
provider page는 raw JSON 그대로 verified S3 bundle에 보존하지만 전화번호는 normalized
row와 projection에 포함하지 않는다.

EPSG:5174 좌표를 WGS84로 변환한다. provider 행정코드 매핑이 검증되기 전에는 확정
0건을 주장하지 않는다.
