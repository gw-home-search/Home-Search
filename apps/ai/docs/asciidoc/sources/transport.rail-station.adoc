== transport.rail-station

KRIC landing은 사람이 release를 검토하는 용도로만 사용한다. collector는 tracked
`id=32` download endpoint만 요청하며, secret 성격의 query parameter를 허용하지
않는다. 2026-07-20 header preflight에서 filename
`전체_도시철도역사정보_20260630.xlsx`, 길이 313,132 bytes,
`application/octet-stream`을 확인했다. source date는 이 검증된 filename에서만 읽고,
HTML을 XLSX로 처리하지 않는다. KRIC는 `User-Agent` 없는 GET에 HTML을 반환하므로
collector는 비밀 없는 고정 `HomeSearchReferenceImporter/1.0` 식별자를 보내고,
응답 media type 검증은 그대로 fail-closed로 유지한다.

공공데이터포털 fileData `15093755`는 `이용허락범위 제한 없음`을 명시한다. KRIC
일반 약관과의 충돌은 프로젝트 책임자가 KRIC에 전화로 문의해 Home Search의 계획된
이용이 가능하다는 답변을 받았다고 진술해 승인했다. 서면 transcript는 없다는 제한을
evidence에 함께 기록했으며 원본 XLSX의 private 보관, 역명·노선·환승·좌표의 내부
가공과 출처표시 응답만 허용한다. 원본 공개 재배포와 전화번호 projection은 금지한다.
license evidence SHA-256은
`14d6a007c272b75456998f5289e08ff8f61cb82f04bb2fc6a72ef9c11327ff0d`다. 전체 artifact
live 검증 전 readiness는 `Partial`이다.

2026-06-30 release의 provider field는 `운영기관명`, `노선번호`, `노선명`, `역번호`,
`역사명`, `역사도로명주소`, `역위도`, `역경도`, `환승노선명`, `데이터기준일자`를
각 normalized field로 exact mapping한다. 이전 표준 명칭은 raw replay 호환을 위한
명시적 alias로만 허용하며 fuzzy header matching은 하지 않는다. 이 변경은
`rail-station-v2`로 구분한다.

검증된 filename의 날짜는 dataset `SOURCE_DATE`로 사용한다. provider별
`데이터기준일자`는 release date와 같음을 요구하지 않고 nullable row provenance로
보존한다. 이 normalization은 `rail-station-v3`, nonblank malformed 날짜를 row 거부 없이
quality warning으로 남기는 계약은 `rail-station-v4`로 구분한다. occurrence identity는
계속 `운영기관명+노선번호+역번호`이고 중복 key는 publication을 차단한다.
