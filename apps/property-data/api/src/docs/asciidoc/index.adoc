== Overview

Home Search exposes the versioned public API needed to search apartment
complexes, display map markers, inspect trade history, and read published
market insight. The generated examples are release artifacts; authentication,
units, pagination, and error behavior remain governed by `docs/API_CONTRACT.md`.
