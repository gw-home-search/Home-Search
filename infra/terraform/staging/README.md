# Staging foundation

This root creates the two-AZ network, one staging NAT gateway, separate public
and CIDR-restricted admin ALBs, private data services, immutable ECR
repositories, log groups, secret containers, and the encrypted ML model EFS.

The primary RDS instance starts with `home_search`; the idempotent bootstrap
task creates `home_search_admin` and `home_search_user` plus least-privilege
roles. Coordinate source stays on the separate RDS instance and is intentionally
excluded from operational backup tasks. RDS master passwords are generated by
AWS through `manage_master_user_password`; Terraform never receives them.

Copy `backend.s3.tf.example` to ignored `backend.tf`, fill only the non-secret
bootstrap outputs, then initialize. A real plan requires explicit admin CIDRs:

```bash
terraform -chdir=infra/terraform/staging init
terraform -chdir=infra/terraform/staging plan \
  -var='admin_allowed_cidrs=["203.0.113.10/32"]'
```

Never put secret values in `.tfvars`, `TF_VAR_*`, plan files, or Terraform
outputs. Secret values are populated by the bootstrap ECS task added with the
workload layer.
